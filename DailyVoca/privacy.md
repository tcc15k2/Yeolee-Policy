## 1. 데일리보카가 하는 일
데일리보카(DailyVoca)는 연상 이미지, 반복 암기, 음성 명령과 미니게임으로 토익·수능 영단어를 외우는 앱입니다. 회원 가입 없이 사용할 수 있습니다.

## 2. 휴대폰에만 저장되는 정보

| 정보 | 내용 | 목적 |
|---|---|---|
| 학습 기록 | 단어별 복습 단계, 복습 예정일, 일자별 학습량과 정답 수 | 복습 일정과 통계 |
| 즐겨찾기와 컬렉션 | 저장한 단어, 처음 완료한 시각 | 즐겨찾기와 컬렉션 표시 |
| 학습 프로필 | 시험 유형, 시험일, 하루 목표, 시작 수준, 고른 단어장 | 오늘의 단어 구성 |
| 오늘의 학습과 게임 | 오늘의 단어 목록과 진행 상태, 게임 최고 기록과 틀린 단어 | 이어서 학습하기와 게임 출제 |
| 앱 설정 | 음성 명령 사용 여부, 알림 설정, 광고 표시 빈도 기록 | 앱 동작 유지 |

## 3. 마이크와 음성
- 음성 명령을 켠 동안에만 마이크 권한을 사용합니다. 권한을 거부해도 음성 명령을 제외한 기능은 쓸 수 있습니다.
- 음성은 **휴대폰 안의 음성 인식기**로만 처리합니다. 앱은 음성을 파일로 저장하지 않고 서버로 보내지 않습니다.
- 사용 통계에는 실행된 명령의 종류(예: 다음, 완료)만 기록합니다. 음성과 인식된 문장은 기록하지 않습니다.

## 4. 외부 서비스

| 서비스 | 전달되는 정보 | 목적 | 끄는 방법 |
|---|---|---|---|
| Google AdMob | 광고 ID와 앱 세트 ID, IP 주소(대략적인 위치 추정에 쓰일 수 있음), 광고 조회·클릭 등 상호작용, 기기 정보 | 광고 표시와 측정, 부정 사용 방지 | 휴대폰 설정에서 광고 ID 삭제. 프리미엄 구독 시 광고 없음 |
| Firebase Authentication (Google) | 앱이 자동으로 만드는 익명 ID. 이름, 이메일, 전화번호는 받지 않음 | 학습 기록을 익명 ID에 연결 | — |
| Cloud Firestore (Google) | 익명 ID와 단어별 복습 단계, 복습 간격, 복습 예정 시각, 복습·실패 횟수, 처음 완료한 시각 | 학습 기록 백업(서울 리전에 저장) | — |
| Firebase Analytics (Google) | 화면 조회, 학습·게임 시작과 종료, 점수와 완료율, 음성 명령 종류, 연속 학습 기념 카드 조회·공유, 평점 요청 표시, 기기 정보, 앱 인스턴스 ID | 앱 개선 | — |
| Firebase Remote Config (Google) | 앱 인스턴스 ID, 앱 버전 | 설정값과 강제 업데이트 안내 | — |
| Firebase Cloud Messaging (Google) | 푸시 토큰 | 알림 전달 | 앱 알림 끄기 |
| Google Play 결제 | 구매 정보(Google Play가 처리하며 앱은 카드 정보를 받지 않음) | 구독 확인 | Google Play에서 구독 해지 |

- 광고는 학습 중에는 표시되지 않습니다.
- 동의가 필요한 지역에서는 Google의 동의 관리 양식(UMP)으로 동의를 받습니다.
- 위 정보는 Google로 전달되며 [Google 개인정보처리방침](https://policies.google.com/privacy)에 따라 처리됩니다.
- 운영자는 개인정보를 판매하지 않습니다. 음성은 어떤 서비스에도 전달하지 않습니다.

## 5. 보관과 삭제
- 앱을 삭제하면 휴대폰에 저장된 정보가 모두 삭제됩니다.
- Firestore의 학습 기록은 이름이나 연락처 없이 익명 ID로만 저장되며, 앱을 삭제해도 자동으로 지워지지 않습니다.
- 앱의 **설정 > 클라우드 학습 기록 삭제**를 누르면 서버의 학습 기록과 익명 ID가 바로 지워집니다. 휴대폰의 학습 기록은 남고, 이후 학습하면 새 익명 ID로 다시 백업됩니다. 앱을 삭제하기 전에 이 메뉴를 사용해 주세요.
- 앱을 쓸 수 없는 경우 tcc15k2@gmail.com으로 요청해 주세요.
- 운영자는 요청을 받으면 확인할 수 있는 범위의 기록을 지체 없이 삭제합니다.
