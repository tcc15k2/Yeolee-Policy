# 찍풀 개인정보처리방침

시행일: 2026-11-13
운영자: Yeolee · 문의: tcc15k2@gmail.com

## 1. 찍풀이 하는 일
찍풀은 수학 문제 사진을 찍으면 AI가 정답과 풀이 과정을 보여 주는 앱입니다. 회원 가입 없이 사용할 수 있으며, 만 14세 이상이 이용할 수 있습니다. 이름, 이메일, 전화번호는 받지 않습니다.

## 2. 문제 사진
- 풀이를 요청하면 고른 문제 사진을 암호화된 연결(HTTPS)로 운영자의 서버에 보냅니다.
- 사진은 Google Cloud 서울 리전의 서버(Firebase Cloud Functions)를 거쳐 AI 풀이를 위해 Anthropic, PBC(미국)의 Claude API로 전달됩니다.
- 운영자의 서버는 풀이를 만든 뒤 사진을 저장하지 않고 버립니다. 사진과 풀이는 휴대폰에만 저장됩니다.
- 사진에 이름, 얼굴, 연락처 같은 개인정보가 나오지 않도록 문제 부분만 찍어 주세요.
- 공유 이미지는 기기에서 만들어 사용자가 고른 앱으로 보내며, 운영자는 받지 않습니다.

## 3. 생년월
첫 실행 때 입력한 태어난 연도와 월로 만 14세 이상인지 휴대폰에서 확인합니다. 입력한 값은 저장하지 않고 확인 결과만 휴대폰에 기록합니다.

## 4. 휴대폰에만 저장되는 정보

| 정보 | 내용 | 목적 |
|---|---|---|
| 풀이 기록 | 문제 사진 축소본, 정답과 풀이, 풀이 시각 | 최근 풀이 다시 보기 |
| 앱 설정 | 연령 확인 결과, 약관 동의 여부 | 앱 동작 유지 |

## 5. 서버에 저장되는 정보
Cloud Firestore(Google Cloud 서울 리전)에 앱이 자동으로 만드는 익명 ID와 함께 저장합니다.

| 정보 | 목적 | 보관 기간 |
|---|---|---|
| 날짜별 풀이 횟수, 광고 보상 잔여 횟수, 마지막 이용 시각 | 이용 한도와 광고 보상 관리 | 90일 동안 이용이 없으면 삭제. 구독이 유효한 동안은 유지 |
| 풀이 요청 기록(요청 ID, 처리 상태) | 같은 요청의 중복 차감 방지 | 1일 |
| 광고 보상 기록(거래 ID, 지급 시각) | 같은 보상의 중복 지급 방지 | 30일 |
| 구독 정보(Google Play 구매 토큰, 만료 시각) | 구독 확인 | 계정 데이터를 삭제할 때 함께 삭제 |
| 신고한 풀이(정답과 풀이 텍스트, 신고 사유, 모델 이름) | 풀이 품질 개선과 부적절한 내용 확인 | 90일. 사진은 보관하지 않음 |

## 9. 안전 조치
- 앱과 서버 사이, 서버와 Anthropic 사이를 모두 HTTPS로 암호화합니다.
- 서버는 앱 무결성 확인과 인증 토큰이 없는 요청을 거절하고, Anthropic API 키는 서버에만 보관합니다.
- 서버 로그에 문제 사진과 풀이 본문을 남기지 않습니다.
