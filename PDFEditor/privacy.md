# PDF Editor 개인정보처리방침

시행일: 2026-11-09
운영자: Yeolee · 문의: tcc15k2@gmail.com
English version: https://tcc15k2.github.io/Yeolee-Policy/PDFEditor/privacy-en.html

## 1. PDF Editor가 하는 일
PDF Editor는 PDF를 읽고 고치는 앱입니다. PDF에 펜·형광펜·글상자·사진·서명을 넣고, 페이지 순서를 바꾸고, 합치거나 나눕니다. 종이 문서를 스캔하거나 사진을 PDF로 만들고, 한글(HWP, HWPX)·워드·엑셀·파워포인트 문서를 볼 수 있습니다. 회원 가입이 없고, 운영자가 직접 운영하는 서버가 없습니다.

## 2. 문서 내용은 기기 밖으로 나가지 않습니다
문서, 스캔한 이미지, 서명은 **기기 안에서만** 처리합니다. 문서 내용, 파일 이름, 서명 이미지를 운영자나 광고·분석 업체에 보내지 않습니다. 문서를 그리는 화면은 인터넷 요청을 차단한 상태로 동작합니다.

앱에는 광고, 사용 통계, 결제를 위한 인터넷 권한이 있습니다. 이 통신은 문서 처리와 분리되어 있으며 아래 4항의 정보만 다룹니다.

## 3. 기기에만 저장되는 정보
| 정보 | 내용 | 용도 | 삭제 |
|---|---|---|---|
| 최근 파일 기록 | 파일 이름, 파일 위치 정보, 크기, 형식, 마지막으로 연 시각, 즐겨찾기 | 다시 열기 | 앱의 목록이나 설정에서 삭제, 앱 삭제 |
| 내 문서 | 앱으로 만들거나 고쳐 저장한 PDF(기기의 문서 › PDFEditor 폴더)와 문서 종류(영수증·계약서·보고서·기타) | 문서 관리 | 앱에서 삭제하거나 파일 앱에서 삭제 |
| 저장한 서명 | 사용자가 그려 저장한 서명 이미지 | 문서에 서명 넣기 | 서명 화면에서 삭제, 앱 삭제 |
| 앱 설정 | 테마, 문서 색 반전, Pro 구매 상태, 출처 표시 사용 여부, 리뷰 요청 시점 계산용 저장 횟수 | 설정 유지 | 앱 삭제 |
| 임시 사본 | 스캔·사진 변환·편집 중 앱 전용 공간에 잠시 만든 파일 | 저장 전 작업 | 저장하거나 화면을 닫을 때, 늦어도 1시간 뒤 자동 삭제 |

이 정보는 기기 밖으로 전송되지 않고, 클라우드 백업과 기기 간 이전에서도 제외됩니다. 문서 비밀번호는 저장하지 않습니다.

무료 버전으로 저장한 PDF의 마지막 페이지 아래에는 "PDF Editor로 만듦"이라는 한 줄이 들어갑니다. 저장 화면에서 끌 수 있고, Pro 사용자에게는 들어가지 않습니다. 이 문구에는 개인정보가 들어가지 않습니다.

사용 이벤트에는 파일 이름, 경로, 문서 내용을 넣지 않습니다. Pro를 구매하면 배너 광고를 요청하지 않습니다. 동의가 필요한 지역에서는 동의한 경우에만 분석 정보를 보냅니다. 미국 주에서 5항의 거부를 선택하면 분석 정보도 보내지 않습니다.

Google의 정보 처리는 [Google 개인정보처리방침](https://policies.google.com/privacy)을 따릅니다.

## 5. 광고 동의와 선택
유럽 경제 지역, 영국 등 동의가 필요한 지역에서는 앱이 Google 동의 화면을 띄웁니다. 동의 내용은 앱 설정의 "개인정보 옵션"에서 바꿀 수 있습니다. 광고 ID는 Android 설정에서 재설정하거나 삭제할 수 있습니다.

**미국 주 개인정보 권리.** 캘리포니아 등 일부 미국 주는 특정 광고 데이터를 개인정보의 "판매" 또는 "공유"로 봅니다. 앱은 관심 기반 광고를 위해 광고 ID 같은 식별자, 앱 실행·탭 같은 사용 기록, IP 주소로 추정한 대략적 위치를 Google과 그 광고 파트너가 받도록 합니다. 운영자가 이 데이터의 대가로 직접 돈을 받지는 않으며, 문서 내용, 파일 이름, 서명은 절대 포함하지 않습니다. 거부하려면 앱 설정의 "개인정보 옵션"에서 "Don't sell or share my data"를 고르세요. 이 메뉴는 해당 주에서 나타납니다. 거부해도 광고는 보일 수 있지만 이 데이터를 바탕으로 하지 않으며, 앱 기능은 같습니다. 해당 주에서는 개인정보 열람, 정정, 삭제 권리도 있을 수 있습니다. 운영자는 이런 정보를 보관하지 않으므로, 도움이 필요하면 9항 주소로 문의하거나 https://myadcenter.google.com 의 Google 설정을 이용하세요.

## 6. 권한
| 권한 | 목적 |
|---|---|
| 인터넷, 네트워크 상태 | 광고, 사용 통계, 결제 |
| 광고 ID (`AD_ID`) | 광고 |
| 저장소 쓰기 (Android 9에서만) | 만든 PDF를 문서 › PDFEditor 폴더에 저장 |

앱은 카메라 권한을 요청하지 않습니다. 스캔은 Google Play 서비스의 스캐너 화면이 처리합니다. 사진은 시스템 사진 선택기로 사용자가 고른 것만 읽습니다. 앱은 사용자가 고르거나 다른 앱에서 넘긴 문서만 읽습니다.

## 7. 보관과 파기
운영자는 개인정보를 직접 수집하거나 보관하지 않습니다. 기기에 저장한 정보는 앱을 삭제하면 사라집니다. 단, 내 문서 폴더에 저장한 PDF는 사용자의 파일이므로 앱을 지워도 남습니다. 외부 서비스의 보관 기간은 각 제공자의 정책과 설정을 따릅니다.

## 8. 아동
앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 정보를 일부러 수집하지 않습니다.
